# 声屿 · 音乐伴侣

网页版个人原型，以沉浸歌词和场景陪伴为核心。当前 UI 按用户提供的 SoundIsle 项目改版，歌词与音乐源方向参考 Folia，保留专注、睡眠定时、推荐纠正、日程和伴侣功能。

## 运行

将 `dist/` 作为静态 HTTP 目录提供服务，无构建步骤。例：在项目目录运行 `python3 -m http.server 8765 --directory dist`，浏览器打开 `http://localhost:8765`。

## 视觉与歌词

- 全屏沉浸视图，流光、字境、星轨三种独立实现的模式。
- 背景从封面取色，随实际音频能量缓慢流动；跨域封面不能取色时使用手选配色。
- LRC 逐行与 YRC 逐词时间轴，同步高亮，点击歌词跳转。
- 可通过文件或粘贴添加歌词；无歌词时显示器乐或暂无歌词状态。
- 伴侣面板可收起；已适配手机布局和低动效偏好。

## 音乐源

进入“音乐库 → 连接与账号”，选择服务、填写自己的 API 地址并验证。

- 网易云：使用与 Folia 相同类别的 NeteaseCloudMusicApiEnhanced 服务，支持扫码登录、搜索、播放、歌单导入、我的歌单、每日推荐及 LRC/YRC 歌词。
- QQ：适配 qq-music-api 3.3.3+，支持搜索、播放、歌单和扫码请求；需后端支持 X-QQ-Session 跨域头，尚未实机联调。
- 酷狗：适配 KuGouMusicApi，搜索、播放、LRC 歌词；扫码/私有歌单未加入。
- Navidrome：Subsonic v1.16.1 令牌认证，搜索、串流、封面和歌单。密码不落盘；刷新后重新登录。
- 本地：保留 IndexedDB 音频导入；内置三首原创合成器乐试听。

这些适配器不包含公共在线音乐后端。与 Folia 网页版相同，需自行部署或连接有使用权限的服务。正式在线服务尚需真实实例和账号联调，歌曲权限、地区、版权与音质由上游决定。

完整参考说明见 SOURCES.md。

## 保留的能力

场景/风格/收藏/排除反馈排序，天气与夜间时段辅助排序；日程增删改及一次性 ICS 导入；专注与睡眠渐弱计时；OpenAI 兼容模型配置、本机规则演示、浏览器语音识别和系统朗读。

## 边界

- 这是静态个人原型，当前部署不运行音乐 API；服务端代理、正式账号系统和多设备同步仍待开发。
- 账号登录态与模型 Key 保留在页面内存，刷新清除。偏好、日程、歌词和导入音乐保存在当前浏览器。
- 跨域音源需要允许 CORS 才能通过 Web Audio 分析；封面取色失败会回退配色。
- 原生 PC/Android、后台播放与设备日历仍为第二阶段。
- 网页计时需要保持页面打开，后台/休眠可能延迟。重复 ICS 规则与 TZID 事件不展开。
- 天气免费服务使用 Open-Meteo（非商业原型），署名 CC BY 4.0。

## 验证

运行 `node tests/providers.test.cjs` 检查时间轴、RFC MD5 向量、请求参数和会话存储。另已通过本机浏览器验证播放、粘贴同步歌词、点击跳转、模式切换、音乐源管理与 390px 手机布局。

## SoundIsle UI 与交互改版（2026-10-29）

以用户提供的 SoundIsle 项目为视觉和交互参考，改为暖黑/琥珀色顶部导航、四场景切换、左侧常驻伴侣、右侧封面律动及独立歌词卡片、底部固定播放器。

- “只听音乐”隐藏对话并扩大听歌区，音乐继续播放。
- 五层本机合成声景：雨、潮涌、火、风、咖啡厅。比例可调，可全静音或恢复场景预设。
- 场景切换联动封面、强调色与声景。
- 自然声随主播放器暂停、全局静音、语音降音量及睡眠停止一同变化。
- 快捷纠正可调整钢琴偏好、音量、雨声与活力场景。
- 设置改为弹窗；现有网易云等音乐源、日程、专注和睡眠功能保留。
- 复用参考项目提供的四张封面，不采用其中固定天气、假定模型连接或器乐演示字幕作为真实数据。

补充测试：`node tests/ambient.test.cjs`。已通过本机浏览器检查纯音乐切换、混音台、聊天调雨声、歌词点击、动效开关、设置弹窗与 390px 手机布局。
