# 声屿 SoundIsle PC 版

React 音乐伴侣：内置「阿屿」陪伴 Agent，通过 QQ 音乐搜索和个人推荐编排播放队列，结合时间、天气、音乐偏好与工作状态选歌，并用 MiniMax 语音交流。

## Android 开发版

手机端设计已通过评审，并接入与 PC 共用的音乐、阿屿、语音和配置逻辑。运行 `npm run mobile:dev`，访问 http://127.0.0.1:5174/ 使用真实移动端服务；`npm run android:debug` 构建安卓调试 APK。手机端连接后直接进入，无需访问码，也不显示锁定入口；默认先通过 USB 连接本机服务。详情和真机安装步骤见 [Android 开发说明](./mobile/README.md)。

Android 0.2 增加独立的原生音乐服务、后台队列、媒体通知与锁屏控制，并接入音频焦点和耳机拔出暂停；PC / 浏览器继续使用 Web Audio。真机后台与系统行为仍需设备验收。

## PC 版本

当前产品版本定义为 **PC 端 1.0.0**，沿用现有音乐、阿屿陪伴、语音和 EQ 功能，通过 Electron 提供桌面窗口。支持 macOS、Windows 和 Linux，桌面窗口最小尺寸为 1100 × 720。

- 开发启动：`npm ci` 后运行 `npm run pc:dev`（构建当前界面后启动；修改代码后需重新运行）。
- 已构建启动：`npm run pc:start`。
- 生成本机可运行应用目录：`npm run pc:pack`。
- 生成当前系统安装包：`npm run pc:dist`，产物位于 `release/`。macOS 为 DMG / ZIP，Windows 为 NSIS，Linux 为 AppImage；建议在各目标系统分别打包。
- 桌面集成检查：`npm run test:desktop`，使用临时用户目录启动真实 Electron 窗口并检查页面、本地 API 和渲染进程隔离。

桌面版内置本地后端，无需另启服务或安装 Node.js（开发和打包仍需要 Node.js）。启动后直接进入播放器，无需4位访问码，也不显示锁定入口。开发首次启动时会从项目 `.env` 导入 MiniMax Key。

MiniMax Key 在「设置 → 音乐与语音 → MiniMax API Key」填写，支持保存、替换与移除，立即生效并在重启后保留；对话、语音识别与朗读共用。Key 仅保存于 Electron 用户目录的 `data/minimax-settings.json`，不会回显到页面或写入浏览器存储。设置中保存的值优先于旧 `.env`，移除后不会自动恢复旧 Key。已配置状态表示存在 Key，实际可用性取决于账户权限和额度。QQ 授权记录和会话密钥保存在同一用户目录的 `data/`，播放进度、EQ 和个人设置保存在桌面浏览器存储中。菜单可打开数据目录；安装包不包含项目 `.env`、`.data` 或开发密钥。桌面版和现有网页的浏览器存储相互独立，不自动迁移授权。

本地服务仅监听 `127.0.0.1`，首次分配空闲端口并保存到 `server-port`，后续复用以保留浏览器设置。端口被占用时会提示启动失败；删除 `server-port` 可重新分配，但将切换浏览器存储来源。桌面本地连接允许回环 HTTP，网页生产部署仍要求 HTTPS 和访问码。

麦克风仅对应用自身的本地页面开放，外部导航和新窗口被拦截。关闭最后一个窗口时 Windows / Linux 退出，macOS 可通过 Dock 重新打开；完全退出时结束本地后端。

macOS 构建默认使用本地临时签名，尚未配置发布证书签名、公证或自动更新；正式对外发布前需补充平台签名凭据。

应用标志采用与界面一致的暖黑与琥珀金，以声波、海面与日光构成「声波浮岛」。矢量源文件为 `public/brand/soundisle.svg`，修改后运行 `npm run icons:generate` 同步生成浏览器图标及 `assets/icons/` 下的 PNG、ICO、ICNS；生成文件随源码保存。桌面开发运行、各平台安装包与导航栏共用这套标志。

## 网页开发与运行

需要 Node.js 22.12+。安装依赖 `npm ci`，复制 `.env.example` 为 `.env`，设置4位数字的 `APP_ACCESS_KEY`，运行 `npm run dev`。默认访问 http://127.0.0.1:3000 并使用访问码解锁，支持以0开头。

陪伴模型使用 MiniMax M3，与 MiniMax 语音共用后端 MINIMAX_API_KEY。未配置或模型调用失败时使用规则回复；设置页显示配置状态，选择离线引擎时不调用模型。

- [阿屿与 QQ 音乐配置、授权及使用](./QQ_MUSIC_AGENT.md)
- [MiniMax 语音配置与使用](./MINIMAX_SPEECH.md)

密钥应保存在被忽略的环境文件或 Cloudflare Secrets 中，不进入前端源码。

## 播放与听感

歌曲来自 QQ 音乐，已移除内置电子乐生成和自然声景混音。底部「EQ 声场」可调整五段频率（±12 dB）、音色预设与左右平衡，支持关闭处理、恢复原声及本机保存。设置入口位于「只听音乐」旁；专辑区域内可切换环绕 / 频谱动效并关闭动画。

播放器的模式按钮依次切换「顺序播放 → 随机播放 → 单曲循环」。随机模式每轮打乱队列、轮内不重复，上一首按实际听歌历史返回；模式会保存在当前浏览器，也可在设置中选择。

刷新或重新打开页面后，保留上次的歌单、当前歌曲和播放进度，点击播放即可继续。记录保存在当前浏览器，仅保存歌曲信息，不保存临时播放链接或授权凭据。

当前歌曲播放到50%时，按当前播放模式预加载下一首音频，切歌时复用缓冲；随机模式提前选定的歌曲与实际下一首一致。更换歌单或播放模式时清理旧预加载，预加载失败不影响当前歌曲，切歌时会重新请求。浏览器会根据网络和设备状态决定实际缓冲量。

## 阿屿的两层记忆

短期记忆每个会话最多24条、12,000字符，刷新同一窗口可继续；24小时未使用后过期。长期记忆将用户明确表达的核心偏好和重要事项压缩成最多2,000字符的摘要，跨对话保留。每轮模型交流后在后台更新摘要，不阻塞开始播放；额外的 MiniMax 调用按用量计费，失败时保留原摘要。

两层记忆共同用于理解意图、选歌和回复，当前要求优先。可在「设置 → Agent 设置」查看摘要、开始新对话或清除全部记忆。PC记忆保存在用户目录的 `data/music-state.json`，不会随安装包发布。推荐与生成歌单可先展示聊天卡片，用户选择播放第一首或加入队列；明确要求听歌或换歌时尝试播放，以播放器实际成功或失败反馈为准。

阿屿内置提示词采用情绪陪伴优先的人设，保留用户提供的原文，个性提示词仍可在设置中调整；旧版内置默认值会自动迁移，已有自定义提示词保留。语音播放期间音乐临时限制在5%（不提高更低或静音的原音量），Agent语音为100%，结束后恢复音乐原音量。

### 歌词与播放动效

歌词区可切换「云阶」（跟随滚动、远处模糊）、「流光」（单句居中、渐亮发光）和「浮游」（文字错落、轻旋入场）。点击「放大」进入全屏沉浸舞台，可点击歌词定位、拖动进度及暂停/继续；按 Esc 返回。歌词样式会保存在当前设备。

专辑区新增「流云」：以封面和曲目主题色构成缓慢流动的背景，光晕强度跟随真实音频低频能量变化；原有环绕与频谱仍可选择。暂停、页面隐藏时停止持续绘制；「关闭动效」和系统减少动态效果设置会关闭持续动画。

视觉设计参考 [Folia](https://github.com/chthollyphile/folia-major) 的流光歌词、弹簧入场和沉浸式排版，在声屿现有 React / Motion / Web Audio 上独立实现，没有引入其渲染器代码。目前 QQ 歌词只有逐行时间，文字渐亮按句内时间比例估算，并非逐字时间戳同步。

当前歌单不再按首数截断：推荐歌单可一键「追加到当前歌单」，保留正在播放的歌曲、进度与歌单标题，重复歌曲自动跳过。我的歌单清单、歌曲查询结果及当前队列都提供「播放歌单」入口，从第一首开始播放；查看歌单不打断播放。完整队列会保存在当前设备，重新打开后恢复。


1.0.2 新增四种歌词舞台：
- **倾诉**：水平主句与倾斜副句交替，弹簧过渡。
- **群唱**：左右对话气泡，当前句高亮，自动跟随。
- **浮名**：巨幅背景字影、前后文叠层和海报式主句。
- **时计**：随歌曲进度推进的表盘、句内进度弧和歌词轨道。

以上方向分别参考 Folia 的 Tilt、Cappella、Fume 和 Pendolo，并在现有组件上独立实现。七种样式均可在歌词预览与沉浸舞台切换、保存，支持点击跳转；时计使用歌曲时间推进，不进行鼓点分离。长歌词可在舞台内滚动阅读。

1.0.3 移除双语切换与译文显示，所有歌词样式统一只显示原文。

1.0.4 将桌面窗口标题栏融入应用导航：保留系统窗口按钮，顶栏空白处可拖动，操作按钮不参与拖动。只听音乐模式按窗口和实际播放栏高度展开，封面动效与歌词区底部对齐。播放列表新增「清空列表」，停止播放并清除当前设备保存的队列；按钮统一增加悬停与键盘焦点反馈。

1.0.5 获取不到歌曲播放链接时静默跳过，按当前播放模式继续寻找可播歌曲；单曲循环也会跳过不可播歌曲。连续失败时每首只尝试一次，整张歌单均不可播则静默停止，点击播放可重新尝试。点击上一首或下一首会立即播放所选歌曲，即使此前处于暂停状态。暂停和清空列表会取消尚未完成的播放请求。
