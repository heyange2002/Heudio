# Heudio 应用 API v1

基础路径 `/api/v1`。成功返回 `{ "data": ... }`；失败返回 `{ "error": { "code": "...", "message": "..." } }`。

除健康检查与音频流外，浏览器请求携带 `X-Heudio-Client: web`。JSON 写入使用 `Content-Type: application/json`。前端 Fetch 使用 `credentials: include`；QQ token 不出现在响应中。

## 健康检查

`GET /health`

返回服务版本、音乐来源、模型是否配置、可选模型 ID 及默认模型。此接口不主动访问 QQ 上游，不暴露上游地址或密钥。

## 音乐

- `GET /music/status`：查询 QQ 登录状态，返回 `provider`、`loggedIn` 与最小用户昵称资料。会访问 QQ `/login/status`。
- `GET /music/search?q=关键词&page=1&limit=20`：只搜索歌曲；搜索词 1～60 字符，limit 1～20。返回标准 `items`、`total`、`more`。
- `GET /music/tracks/:mid/playback?quality=128`：返回应用内 `streamPath`、`preview` 和实际/请求音质；不会返回 CDN vkey。支持 `m4a`、`128`、`320`、`flac`、`ape`、`best`。
- `GET /music/stream/:mid?quality=128`：QQ 音频代理，支持单段 `Range`；透传 200/206/416 和音频相关头。只请求 QQ CDN 白名单，逐跳检查重定向，不接收任意 URL。
- `GET /music/tracks/:mid/lyrics`：返回 `{ format: "lrc", text, translation }`；无歌词时返回空文字。
- `GET /music/playlists/:id`：读取当前可访问的 QQ 歌单，数字 ID，返回标准 `items` 和歌单名。本人不公开歌单的专用接口暂未适配。

歌曲统一字段：`id`、`provider=qq`、`mediaId`、`title`、`artist`、`duration`（秒）、`cover`、`source`、`genre`、`scenes`。

播放地址缓存只在本应用会话内保存一分钟，最多 30 条。切换账号或退出会清除。音质和歌曲可用范围由上游决定；有 `preview=true` 时页面标明试听。

## 扫码和会话

- `GET /auth/channels`：读取上游当前可用的扫码通道。
- `POST /auth/qr`，JSON `{ "channel": "qq" }`：可用通道 `qq`、`wechat`、`qqmusic`，返回 `{ key, image, channel }`。前端按实际能力显示选项。
- `GET /auth/qr/:key`：轮询 `code`、`loggedIn`、`message`。801 等待，802 待确认，803 成功，800 过期或失败。
- `DELETE /auth/qr/:key`：取消当前应用会话拥有的二维码。
- `DELETE /auth/session`：退出 QQ 会话，清空应用播放链接缓存并取消当前会话未完成的二维码。

每个二维码绑定随机应用会话；其他会话无法领取它。成功扫码时后端提取 `qqmusic_session`，只向 QQ API 转发 `X-QQ-Session`。浏览器只得到 HttpOnly 的 `heudio_session` Cookie。

应用会话默认有效一天，刷新页面仍可使用；应用后端重启丢失内存映射，需要重登。每会话最多五个未过期二维码。二维码在应用侧保留四分钟，以覆盖上游有效期及确认宽限。

## 天气

- `GET /weather/cities?q=Shanghai`：固定请求 Open-Meteo 地理编码服务。
- `GET /weather/current?lat=30&lon=120`：固定请求天气服务，验证经纬度范围。返回原天气结构，页面负责天气文字转换与缓存。

## 伴侣

`POST /companion/chat`

```json
{
  "model": "后端允许的模型 ID",
  "messages": [{ "role": "user", "content": "帮我专注一下" }],
  "context": { "scene": "focus", "track": "月光潮汐", "playing": false, "titles": [] }
}
```

系统提示由后端构建，客户端仅传 user/assistant 历史和受限上下文。最多 24 条，每条不超过 8000 字符，总请求体不超过 64 KiB。返回 `{ content, model }`。

模型输出 `reply` 和可选 `action` 的 JSON 文字，由前端解析，再验证动作类型与参数后执行。支持场景、播放/暂停/下一首、音量、专注、睡眠、自然声比例和音乐风格偏好。成功执行结果由播放器反馈，不能只凭模型的文字判断。

## 失败与限流

常见状态：400 参数无效、401 需要登录、403 来源/应用头不符、404 未找到、409 会话变化、413 内容过长、415 非 JSON、422 无播放地址、429 请求过频、502 上游失败、503 未配置模型或会话容量满、504 上游超时。

普通请求按连接来源 IP 每分钟最多 180 次，模型请求 15 次。反代时可能由同一个代理 IP 共用限额；当前为个人单实例设计。内存会话上限 1000，过期记录定期清理。

CORS 只允许配置的 Origin，携带凭据；无通用转发端点，客户端不能指定任意上游 URL。响应不返回 QQ cookie、模型 Key 或内部异常详情。
