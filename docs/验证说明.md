# v0.4 验证说明

日期：2026-10-29。当前项目为独立前端、Heudio 后端、QQ Music API 三服务。

## 自动检查：通过

`npm test`：11 项后端 HTTP 集成测试全部通过，前端 API/歌词回归与声景回归两组通过。

覆盖：搜索参数编码与规范化、二维码所属会话、HttpOnly Cookie、凭据不返回前端、退出后状态、延迟扫码响应不能重新登录、音频 Range/206、短时播放链接缓存、试听标记、无链接失败、歌词和翻译、歌单、CORS、应用请求头、禁止任意代理、QQ CDN 重定向校验、天气经纬度、服务端模型密钥与模型允许列表、LRC/YRC 时间轴、五层声景随暂停/静音/语音/睡眠联动。

`npm run build:frontend`：通过，生成 `frontend/dist/`。所有前后端 JS 语法检查通过；Markdown 本地引用检查无缺失；`git diff --check` 通过；`docker compose config --quiet` 通过。

后端自动测试使用与 QQ API 3.3.5 契约一致的模拟上游，验证应用边界与状态处理，不等于真实账号、网络或完整曲库已验证。

## 真实三服务联调

实际安装 `@yakult-green-tea/qq-music-api@3.3.5` 并启动：前端 5173、Heudio 后端 3001、QQ API 3200。

- 前端首页、经开发代理访问的 `/api/v1/health`、QQ 登录状态及扫码通道均返回 200。
- 浏览器“保存并验证”显示“后端已连接 · 未登录”，实际读出手机 QQ、微信、QQ 音乐 App 三个扫码选项。
- 浏览器试听播放时间正常推进、暂停正常；原播放器及声景 UI 保留。
- 模型未配置时，在设置弹窗内明确显示未配置提示。
- 390px 手机设置弹窗适配，页面宽度与视口同为 390px，无横向溢出。测试后已恢复默认尺寸。
- 浏览器未捕获到 JS 错误。
